## 발표·자습 검수

브라우저의 1280×720 발표 레이아웃에서 34장을 차례로 열어 캡처하고 모든 장을 검토했습니다. 본문 32px, 제목 44px 기준입니다. 본문과 하단 출처의 겹침 0건, 화면 경계 밖 본문 0건, 슬라이드 하단과 출처 하단의 화면 이탈 0건입니다. 생성 이미지와 공식 화면의 로딩을 확인했습니다.

캡처와 측정값은 로컬 `output/history-review/slides/`, `output/history-review/metrics.json`에 저장합니다. 해당 경로는 Git 제외 자료입니다. 출처 화면의 원문은 확대 버튼과 공식 링크로 열 수 있습니다. 영상은 브라우저 재생 컨트롤을 사용합니다.

자습 자료는 390×844 화면에서 34개 장과 노트·출처·용어를 확인했습니다. 문서 폭 390px, 가로 넘침 0px입니다. 이미지와 영상의 크기를 미리 확보해 목차 이동 위치를 유지하며, ah-26 직접 링크의 도착 위치를 확인했습니다.

내용 검토에서는 같은 요구의 연속성, 연구와 제품 연표, 현재 문서와 과거 발표의 구분, 실행에서 컨텍스트 관리로 이어지는 연결을 대조했습니다. `npm run check`와 `npm run test:lecture`로 기존 230장·회차별 240분·실습 525분, 새 모듈의 34장·60분, 필수 노트·출처·미디어 도메인을 검사합니다.
