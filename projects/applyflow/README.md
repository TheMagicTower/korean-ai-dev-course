# ApplyFlow · 개인 브라우저 채용 공고 도구

가상 공고를 저장하고 관심→지원→면접→합격/종료로 관리합니다. 이번 구현은 기존 교재 예제의 확장입니다. 로그인·서버·기기 동기화가 있는 SaaS는 아닙니다.

## 실행과 첫 사용

저장소 루트에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765/projects/applyflow/`를 여세요. Node 검사는 `node projects/applyflow/test-model.cjs`입니다. API 키·패키지 설치는 필요하지 않습니다.

1. 가상 공고 3개로 시작합니다. 직접 회사·직무를 입력할 수도 있습니다.
2. 지원 상태를 바꾸고 회사 또는 직무를 검색합니다. 검색과 상태 필터는 동시에 적용됩니다.
3. JSON 백업을 내려받습니다. 가져오기에서 파일을 선택하거나 JSON을 붙여넣고 검증합니다.
4. 미리보기를 읽고 전체 교체 동의에 체크한 뒤 교체합니다. 빈 목록 백업도 전체 삭제를 뜻하므로 확인이 필요합니다.
5. 개별 공고 삭제는 페이지 안의 확인 영역에서 회사·직무를 읽고 취소 또는 삭제 확정합니다. 삭제를 되돌리려면 이전 백업이 필요합니다.

## 작업 계약

- 개인 검증용 브라우저 도구, 가상 공고 최대 200개.
- 기존 기능: 공고 추가·상태 변경·검색·상태 필터·브라우저 저장·JSON 내보내기.
- AF-105: version 1 백업 가져오기, 형식/필드/상태/중복 ID/건수 검증, 미리보기, 별도 전체 교체 동의.
- AF-106: 공고별 삭제 확인과 취소, 저장 실패 시 이전 상태 유지.
- 파일 1 MB 이하, 붙여넣기 1,048,576 문자 이하. 회사 60자·직무 100자·ID 1~100자.
- 가져오기에서 허용한 네 필드(id/company/role/status)만 사용합니다. 임의의 추가 필드는 버립니다.
- 가져오기 미리보기는 JSON 수정·다른 변경 저장·다른 탭 변경 시 무효화합니다.
- 읽을 수 없는 저장 자료는 자동 초기화하지 않고 편집을 막습니다. 저장 실패도 이전 메모리/저장 자료를 유지합니다.
- HTML을 입력해도 데이터는 textContent로 표시합니다.

## 검증과 제한

[evidence/tests.txt](evidence/tests.txt)에 실제 실패→통과 명령/출력을 기록했습니다. [단계 기록](evidence/events.jsonl), [인계 응답](evidence/response.md)을 함께 봅니다. 서브에이전트 구현 시각이며 사용자 학습 시간·전체 새 프로젝트 개발 시간과 다릅니다.

범위 내 자체 검토: 입력 파서와 삭제는 불변 변경, 저장 성공 후에만 UI 상태 확정, 손상 자료 덮어쓰기 금지, 미리보기 이후 내용 변경 시 동의 무효화, 비동기 파일 읽기 순서 확인, 상위 교재 상대 경로 확인.

브라우저의 실제 파일 업로드/다운로드·삭제 확인 영역·모바일 상호작용은 루트 에이전트 통합 검증 대상입니다. 다른 탭에서 동시에 편집하면 마지막 저장이 앞선 변경을 덮을 수 있습니다. 다중 사용자/협업 동시성 보장은 범위 밖입니다. 브라우저 데이터 삭제·시크릿 모드 종료·기기 변경에 대비한 서버 백업은 없으므로 가상 자료로 체험하세요.

## 삭제 확인 보완

루트의 통합 검증 피드백을 받아 삭제 확인을 페이지 내부 영역으로 변경했습니다. 취소 버튼으로 초점을 이동하며 취소·삭제 후 검색 입력으로 돌아갑니다. 확정 시 현재 대상 존재 여부를 다시 확인하며 다른 탭의 갱신과 저장 성공은 이전 확인을 무효화합니다. `node projects/applyflow/test-delete-ui.cjs`는 실제 app.js와 최소 DOM 포트로 취소 불변·저장 실패·확정·외부 갱신 무효화를 검증합니다. 이는 실제 브라우저 검증과 구별합니다. 보완 요청·응답·단계 시각은 evidence/followup-prompt.txt, followup-response.md, events.jsonl에 있으며 최초 인계 기록을 보존했습니다.

독립 검토에서 발견한 비동기 파일 읽기 중 이전 백업 미리보기·동의가 남는 오류를 수정했습니다. 새 파일 내용이 도착할 때 이전 미리보기와 동의를 폐기하며, 지연된 file.text()를 사용하는 회귀 검사로 실패와 수정 후 통과를 기록했습니다.
