# 한국어 실행 예시

각 도구에서 명시적으로 스킬을 선택한 뒤 아래 요청을 사용합니다. Codex는 `$kdev-plan`, Claude Code는 `/kdev-plan`처럼 호출합니다.

| 스킬 | 요청 예시 |
|---|---|
| kdev-start | 혼자 쓰는 독서 기록 도구의 사용자·입출력·제외 범위·완료 조건을 정리해 주세요. |
| kdev-model | 이 오류 진단에 지금 접근 가능한 모델·사고 수준을 고르고 선택 이유와 예산을 기록해 주세요. |
| kdev-plan | 문의 관리 목업을 먼저 조작해 보고 상태 전이·권한·API·데이터를 도출한 뒤 이번 구현 작업을 나눠 주세요. |
| kdev-build | 합의한 기록 검색 기능만 구현하고 대표 입력으로 검증해 주세요. |
| kdev-debug | 새로고침하면 기록이 사라지는 원인을 진단해 주세요. 이번에는 코드를 수정하지 마세요. |
| kdev-review | 이 변경을 개인용 완료 기준으로 검토만 해 주세요. 블로커가 없으면 종료해 주세요. |
| kdev-deliver | 제출 버전에서 저장·재실행·대표 실패를 확인하고 완료 여부와 미확인을 알려주세요. |
| kdev-handoff | 이미 통과한 검토와 현재 버전, 남은 필수 작업·예산을 다음 세션에 인계해 주세요. |

실제 API·저장·권한이 없는 목업은 제품 구현 완료로 제출하지 않습니다. 프로젝트의 실제 위험과 수용 조건에 비례해 검증합니다.
