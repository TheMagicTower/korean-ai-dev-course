# 사례 연구 추가분의 가상 수강생 점검

기존 `personas.json`의 동일한 다섯 가상 수강생으로 2·3회차의 새 슬라이드와 `/cases/` 페이지를 두 차례 문서상 점검했습니다. 실제 학생에게 보여주거나 이해도·소요 시간을 측정한 결과가 아닙니다.

| 가상 수강생 | 1차에 던진 질문 | 2차에 자료에서 확인한 연결 |
| --- | --- | --- |
| 민서(P01) | 신경 연결지도를 받았다고 게임 입력이 바로 가능합니까? | 2회차 24번의 보드→인코더→부분 회로→디코더→합법 수 흐름과 사례 페이지의 단계 지도가 답합니다. |
| 준호(P02) | 멋진 게임 화면만으로 회로 성능을 주장할 수 있습니까? | 2회차 25번 퀴즈와 사례 페이지의 기준선·시드·타임아웃 질문이 화면과 검증을 나눕니다. |
| 서연(P03) | Jev의 결과가 독자에게 보이는 가치와 어떻게 연결됩니까? | 3회차 15–16번이 NASA 발췌→분류→기사 초안→근거 확인→편집자 승인 경로를 보여줍니다. |
| 도윤(P04) | `confidence: 0.99`면 기사 사실성과 자동 발행이 검증됐습니까? | 3회차 17번 퀴즈와 사례 페이지가 단일 응답값, 정확도 측정, 발행 정책을 구분합니다. |
| 유진(P05) | 사례를 흥미로운 구경으로 끝내지 않고 자신의 제품에 어떻게 옮깁니까? | 두 사례 페이지의 ‘내 프로젝트에 적용’과 발표 노트의 경계·실패 조건 질문이 자신의 MVP 계약으로 돌아오게 합니다. |

1차 점검에서는 자료와 실제 구현 범위의 혼동, 사례와 자기 프로젝트의 연결 부족을 우려했습니다. 2차 점검에서는 각 사례에 실제 화면, 근거, 해석의 한계, 전이 질문이 모두 있는지 확인했습니다. 남는 한계는 실제 학습자의 반응과 실습 소요 시간을 아직 관찰하지 못했다는 점입니다.
