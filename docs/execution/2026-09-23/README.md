# 실제 서브에이전트 구현 기록

2026-09-23 세 프로젝트를 독립 에이전트에 위임한 실행 기록입니다. prompts/는 실제 읽도록 전달한 작업 지시이며 dispatch.json은 위임 메시지입니다. 프로젝트별 evidence/events.jsonl의 UTC 시각은 에이전트가 단계 진입/완료 때 기록한 관찰값입니다. 각 에이전트의 공개 응답과 실행 결과만 포함하며 내부 추론 전체나 모든 도구 호출의 원시 로그는 아닙니다.

단계 시간은 연속된 마일스톤 간 경과 시간으로 도구 호출·대기·검토를 포함합니다. 병렬 에이전트 시간을 합한 값은 전체 실제 경과 시간이 아닙니다. ApplyFlow는 기존 구현을 재사용하므로 신규 프로젝트와 동일 조건의 속도 비교가 아닙니다. 학습자의 예상 소요 시간이나 6배 생산성 증명으로 사용하지 않습니다. 전체 토큰·비용은 측정 도구가 제공하지 않으면 미측정으로 남깁니다.

실행 기록은 각 projects/<name>/evidence/ 아래에 있습니다. 최종 통합·브라우저 검증·배포 시간은 주 에이전트의 별도 기록으로 연결합니다.

공개 진행 응답의 시각과 실제 검사 명령 시각은 다릅니다. 테스트는 구현 중에도 반복 실행되므로 보고 간 막대는 상호 배타적인 실제 작업 구간이 아닙니다. 원본 시각을 수정하지 않고 tests.txt와 함께 읽습니다.
