# FlyBlock Arena

실행 가능한 한국어 **인간 대 초파리 연결지도 유도 부분 회로** 블록 게임입니다. 전체 초파리 뇌를 실행하는 게임이 아닙니다. 실제 공개 연결 데이터에서 선정한 **12개 뉴런·13개 연결**을 사용하며, 게임 입력과 출력 해석은 새로 만든 공학적 어댑터입니다.

## 실행과 온보딩

저장소 루트에서 다음 명령을 실행한 뒤 `http://localhost:8765/projects/flyblock/`를 여세요.

```sh
python3 -m http.server 8765
node projects/flyblock/test-realtime.cjs
node projects/flyblock/test.cjs
```

Node.js 22에서 검증했습니다. 플레이에는 패키지 설치·API 키·서버 처리·외부 네트워크가 필요하지 않습니다. 정적 서버는 파일만 제공합니다.

**경기 시작**을 누르면 게임 영역에 키보드 포커스가 연결됩니다. ←/→ 이동, ↑ 회전, ↓ 한 칸 빠르게, Space 즉시 낙하, P 일시정지·재개를 사용하세요. 화면의 터치 버튼도 동일하게 작동합니다. 흰 테두리는 현재 낙하 중인 블록, 반투명 블록은 착지 예상 위치입니다. 시작 전에는 시간이 흐르지 않습니다.

다른 입력란·링크·페이지·창으로 포커스를 옮기면 경기를 일시정지합니다. 자동으로 재개하지 않으며 P 또는 재개 버튼을 눌러야 합니다. 편집 가능한 입력과 Ctrl/Alt/Meta/Shift 조합은 가로채지 않습니다. 버튼 자체에 포커스가 있을 때는 Space를 게임 입력으로 쓰지 않으므로 기본 버튼 조작도 유지됩니다.

## 현재 실시간 규칙과 완료 범위

- 각 보드 6열×10행, 세 색의 두 칸 블록입니다. 두 칸은 낙하 중 함께 움직입니다. **잠길 때 가로 두 칸은 각 열의 높이로 따로 내려앉습니다.** 회전은 좌우 한 칸 벽 보정만 허용하며 천장 밖으로 나가지 않습니다.
- 시뮬레이션은 50ms 고정 틱입니다. 두 보드는 독립 진행하고 블록은 500ms마다 한 칸 자동 낙하합니다. 사람의 한 수를 기다리지 않고 상대가 진행합니다.
- 실제 신경회로가 현재 위치에서 도달 가능한 수 중 목표를 고릅니다. 상대는 150ms마다 목표 경로의 한 동작을 실행하며 자동 중력도 받습니다. 선택 목표가 도달 불가능해지면 실제 회로로 다시 판단합니다. 가짜 봇으로 대체하지 않습니다.
- 같은 색 상하좌우 연결 4개 이상을 동시에 제거하고 중력을 적용합니다. 반복 제거는 연쇄입니다.
- 지운 색 블록 4개당 상대에게 방해 블록 1개를 보냅니다. 공격은 즉시 상대 대기열에 넣고 **상대의 다음 블록 잠금 때** 적용합니다. 같은 틱 공격은 모아 전달합니다. 진행 중인 블록과 충돌하는 중간 삽입을 피하기 위한 규칙입니다.
- 방해 블록은 가장 낮은 열부터, 동률이면 왼쪽부터 쌓입니다. 제거되는 색에 인접한 방해 블록도 제거됩니다.
- 중앙 생성 위치가 막히거나 방해 블록을 받을 공간이 없으면 패배합니다. 같은 틱 양쪽 모두 막히면 무승부입니다.
- **활성 플레이 120초**에는 누적 제거한 색 블록 수로 판정합니다. 일시정지 시간은 포함하지 않습니다.
- 계정·서버·온라인 매칭·지속 저장은 없습니다. 새로고침하면 기록이 사라집니다. 필요하면 `기록 저장`으로 JSON을 다운로드하세요.

### 타이밍 리플레이

리플레이는 `flyblock-realtime-replay` 형식이며 런타임·모델·데이터 버전, 시드, 종료 틱, **틱별 실제 사람 입력**을 저장합니다. 신경 판단은 같은 버전과 시드로 재실행합니다. 일시정지 구간에는 틱이 진행하지 않으므로 재생은 활성 플레이 시간만 복원합니다. 재생 중 실시간 이동 입력은 차단됩니다. 일시정지는 가능합니다.

UI의 `타이밍 다시 보기` 또는 프로그램의 `FlyRealtime.replay(recording)`으로 재현할 수 있습니다. JSON 파일을 불러오는 UI는 아직 없습니다. 이전 라운드 방식의 수 목록과 다른 형식이며 구 버전을 받으면 오류로 거부합니다. 재시작·재생 시작 때 기존 실행 프레임을 취소하므로 중복 실행하지 않습니다.

## 실제 데이터와 원본 연구

연구 저장소: [philshiu/Drosophila_brain_model](https://github.com/philshiu/Drosophila_brain_model/tree/91bdd1e7dcf193f3e7ca5a8933497fcef63b7960)

- 고정 커밋: `91bdd1e7dcf193f3e7ca5a8933497fcef63b7960`
- 데이터: `Connectivity_783.parquet` / FlyWire v783. 원본 100,804,642 bytes, 15,091,983 연결 행입니다.
- 원본 SHA256: `efeb23fb99098e9c390f6869969b2a121a2ee92c833cfc45ecb2c1d8e1af0347`
- 저장소 라이선스: MIT, Copyright (c) 2023 Philip Shiu and Nico Spiller. 원문 [vendor/LICENSE](vendor/LICENSE)을 동봉했습니다. 원본 [model.py](vendor/model.py)·[Readme.md](vendor/Readme.md)도 참조용으로 보존했습니다.
- 뉴런의 64비트 ID는 JS 정밀도 손실을 피하도록 문자열로 저장합니다. 전체 ID·서명된 연결 수·채널은 [data/circuit.json](data/circuit.json)에 있습니다.

`prepare.py`는 가장 강한 양의 연결부터 정렬하고, 서로 다른 12개 뉴런으로 된 6쌍을 고릅니다. 그 12개 사이의 **원본에 실제 존재하는 모든 연결**을 보존합니다. 따라서 강한 흥분성 6개뿐 아니라 실제 억제성 연결 7개도 포함합니다. 가짜 연결을 만들거나 원본 연결 수를 학습으로 바꾸지 않았습니다. 게임을 위한 채널 선택이며 해부학적으로 완결된 감각/운동 회로라는 주장은 하지 않습니다.

재추출(선택 사항):

```sh
python3 -m pip install pyarrow==25.0.1
python3 projects/flyblock/prepare.py
```

원본 파일이 `/tmp/flyblock-connectivity-783.parquet`에 없으면 고정 커밋에서 약101MB를 내려받습니다. 원본 SHA256이 일치하지 않으면 중단합니다. `--source /path/to/file.parquet`로 기존 다운로드를 재사용할 수 있습니다. 생성되는 두 파일은 JSON 및 브라우저/Node 공용 JS 래퍼입니다. 원본 대용량 데이터는 저장소에 포함하지 않습니다. 최초 연구·다운로드·PyArrow 설치 시간도 이번 구현의 시작 이후 실제 경과 시간에 포함되어 있습니다.

## 모델과 사람이 설계한 부분의 경계

원본 연구의 LIF 방정식/상수를 참고한 **새로운 축소 브라우저 구현**입니다. 실제 Brian2 전뇌 모델을 실행한 결과가 아닙니다. 원본 논문과 정확도 동등성을 검증하지 않았습니다.

| 부분 | 구현 |
|---|---|
| 실제 연결 | 12개 원본 뉴런의 유도 부분그래프, 원본 signed connectivity 그대로 |
| 막전위 | 휴지·리셋 −52mV, 발화 −45mV 초과, 막 시정수20ms |
| 시냅스 | 원본 연결 수 ×0.275mV, 감쇠5ms, 전달 지연1.8ms |
| 시간 적분 | Euler dt0.2ms, 300ms 모의 시간, 일반 불응기2.2ms |
| 입력 자극 | 시드 기반 Poisson Bernoulli 근사, 자극 뉴런은 불응기0, 전압 증가68.75mV |
| 인코더(사람 설계) | 각 열 `40 + 빈칸 수×10 + 맨 위가 A색이면35` Hz |
| 디코더(사람 설계) | 합법 수의 기준 열에 해당하는 출력 발화 수×10, 방향이 발화 수 mod4와 같으면1점 가산, 동률은 열·방향 순 |

각 신경 판단에서 신경 상태는 초기화됩니다. 학습·기억·생물학적 시각·자연스러운 초파리 행동을 구현하지 않습니다. 강한 연결 선택·공간을 선호하는 인코더·합법 수 필터 모두 결과에 기여합니다. 따라서 아래 결과를 초파리의 지능이나 연구 전뇌 모델의 게임 능력으로 해석하면 안 됩니다. 발화 출력이 없으면 오류로 멈추며, 무작위 또는 규칙 봇으로 은밀히 대체하지 않습니다.

## 실제 검증과 과거 라운드 측정

`test-realtime.cjs`는 실제 낙하·충돌·회전·빠른/즉시 낙하·일시정지·공격 대기열·동시 종료·타이밍 재생·키보드 포커스/편집 경계·프레임 취소와 재개를 검사합니다. 이 어댑터 시험은 실제 브라우저 검증과 구분합니다. [업데이트 시험 기록](updates/keyboard-realtime-01/tests.txt)을 확인하세요.

`test.cjs`는 기존 라운드 엔진의 제거·방해 블록·2연쇄·잘못된 배치·입력 불변성·재생·종료 조건·결정적 발화·신경 수의 합법성을 검사합니다. **연결을 제거하면 출력 뉴런 발화가0**이라는 대조 실험도 수행합니다. 첫 2연쇄 fixture가 잘못되어 실패한 기록과 올바른 fixture로 수정한 재실행 기록을 모두 [evidence/tests.txt](evidence/tests.txt)에 보존했습니다.

**아래는 최초 구현의 구 라운드 방식 결과이며 현재 실시간 모드의 성적이 아닙니다.** 같은 시드1–20, 구 라운드 규칙으로 회로와 두 기준선을 대결한 실제 결과입니다. 실패 경기를 제외하지 않습니다. 지연은 실행 환경에 따라 달라집니다. 현재 UI에서는 원본 표만 보존하며 새 실시간 성적으로 표시하지 않습니다.

| 상대 | 회로 승 | 무 | 패 | 실패 |
|---|---:|---:|---:|---:|
| 무작위 합법 수 | 16 | 0 | 4 | 0 |
| 낮은 높이 우선 | 3 | 1 | 16 | 0 |

원본 측정은 동결했습니다. `test.cjs` 재실행은 기본적으로 파일을 덮어쓰지 않습니다. 별도 경로의 재측정 기록이 필요하면 `FLYBLOCK_EVALUATION_OUTPUT` 환경변수에 저장 경로를 지정하세요.

구체적 시각·중앙 지연·총 수·제거량: [evidence/evaluation.json](evidence/evaluation.json). 표본이 작고 인코더와 디코더를 포함한 결과이므로 우월성 검증이 아닙니다. 연결을 섞는 대조·인코더 고정 대조·원본 Brian2와의 수치 비교는 후속 연구입니다.
