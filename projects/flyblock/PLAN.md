# FlyBlock 구현 계약과 계획

기존 승인된 6×10, 3색, 4개 연결 제거, 동시 방해 블록 라운드 규칙을 구현합니다. 새 엔진·화면·어댑터를 작성하며 기존 연구의 전뇌 시뮬레이터를 그대로 실행하지 않습니다.

1. 고정 커밋 `91bdd1e7dcf193f3e7ca5a8933497fcef63b7960`의 FlyWire v783 실제 연결 데이터를 다운로드합니다. 서로 다른 6개 강한 흥분성 연결을 입력/출력 채널로 고르고 그 뉴런 사이 실제 유도 부분그래프를 보존합니다. 원래 가중치·뉴런 ID·원본 SHA256과 재추출 코드를 공개합니다.
2. 연구 모델의 LIF 상수와 방정식에 기반한 브라우저 Euler 시뮬레이션을 작성합니다. 게임 인코더/디코더는 인위적이며 생물학적 해석은 하지 않습니다. 원본 Brian2 실행 및 정확도 동등성은 주장하지 않습니다.
3. 순수 JS 게임 엔진, 고정 fixture 테스트, 신경 출력/결정성/연결 제거 대조 테스트를 만듭니다.
4. 한국어 반응형 화면에서 사람 대 부분 회로 경기, 시드 재시작, 리플레이, 현재 신경 발화·지연·기준선 비교를 제공합니다. 반복 재생은 동일 수열과 컨트롤러 버전으로 검증합니다.
5. 실제 실행 로그·시험 출력·소요 시각을 남깁니다. 브라우저 시각 점검은 루트 에이전트가 통합 단계에서 추가합니다.

파일: `prepare.py`, `data/circuit.json`, `data/circuit.js`, `vendor/`, `engine.js`, `controller.js`, `app.js`, `index.html`, `style.css`, `test.cjs`, `README.md`, `evidence/`.

범위: 로컬 교육용 PoC. 계정·서버·온라인 매칭 없음. 80라운드 제한에 도달하면 지운 색 블록 수로 판정합니다(진행 불능 패배가 우선). 인간 입력은 네 방향 두 칸 블록의 기준 열과 방향을 선택합니다.
