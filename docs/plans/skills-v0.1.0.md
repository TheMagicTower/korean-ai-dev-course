# 한국어 스킬 패키지 Implementation Plan

> For agentic workers: 합의된 패키지 설계를 기준으로 구현하고 독립 검토를 수행합니다.

**Goal:** 현재 프로젝트에 설치 가능한 한국어 스킬 8개, 도구별 설치 안내, 한 줄 프롬프트와 ZIP을 만듭니다.
**Architecture:** 각 skills/<name>/SKILL.md는 독립적으로 동작합니다. 공통 핵심 규칙만 짧게 반복하고 프로젝트 문서는 설치에 의존하지 않습니다. 기존 파일을 보존하는 수동 복사를 기본으로 제공합니다.
**Tech Stack:** Markdown, ZIP, Python 표준 라이브러리 기반 패키지 검증.

## Chunk 1: 배포 가능한 첫 묶음

- [x] `kdev-plan`에 목업 → 조작 → 규칙·권한·API·데이터 도출과 임시 동작 표시를 구현합니다. 독립 설치된 스킬로 DB 선행 강제 여부와 목업/제품 완료 구분을 검증합니다.
- [x] 8개 스킬의 한국어 메타데이터와 단계별 수행 지침을 작성합니다.
- [x] INSTALL.md와 Codex/Claude Code 한 줄 프롬프트, 충돌·업데이트·제거 안내를 작성합니다.
- [x] 구조 검증과 임시 프로젝트 설치·충돌 시 보존 검증을 수행합니다.
- [x] 서로 다른 수준의 요청에 대한 독립 행동 검증을 수행합니다.
- [x] ZIP·체크섬과 검증 범위를 기록하고 기존 설계 문서 상태를 갱신합니다.

GitHub 대상 주소는 사용자 응답 후 확정합니다. 공개 업로드와 두 제품의 실제 새 세션 호출은 별도 상태로 기록합니다. HTML 교재는 이 묶음의 검증된 버전을 기반으로 다음 제작 단계에 연결합니다.
