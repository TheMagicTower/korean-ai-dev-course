# HTML 교재와 공개 배포 계획

사용자가 theMagicTower 조직 저장소 생성과 강의 자료 제작을 승인했습니다.

- [x] 한국어 읽기 중심의 정적 HTML 교재를 만듭니다. 소개·시작하기·4주 수업·워크북·공식 조사 부록을 연결합니다.
- [x] 주차별 120분 시간표, 개념·시연·프롬프트·개인 실습·완료 판정·강사 메모를 작성합니다.
- [x] 목업→규칙·API·DB 역설계와 프로젝트 수준별 범위·예산을 유지합니다.
- [x] GitHub 주소를 확정하고 스킬 ZIP·체크섬을 갱신합니다. 공개 자료에서 로컬 개인 경로를 제거합니다.
- [x] 탐색·프롬프트 복사·체크리스트 저장·모바일·인쇄를 브라우저로 검증합니다.
- [x] 공개 저장소·Release·Pages를 배포하고 실제 링크와 다운로드를 확인합니다.

한 화면에 한 단원을 읽는 좌측 목차 구조, 미색 배경·짙은 청록 강조, 한국어 가독성을 고려한 글꼴을 사용합니다. 필수 기능은 로컬 HTML에서도 동작하고 온라인 Mermaid 로딩 실패 시 도식의 텍스트 원본을 남깁니다. 자동화 스케줄러 구축은 필수가 아닌 운영 심화 부록입니다.
