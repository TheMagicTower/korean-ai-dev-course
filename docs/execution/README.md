## 기록 해석

이벤트 간 경과시간에는 작업·도구 호출·대기·검토가 포함될 수 있습니다. 병렬 작업자의 시간을 단순 합산하면 전체 경과시간이 되지 않습니다. 최초 인계 시간과 최종 통합 검증 시간도 서로 다른 단계입니다. 비교 실험은 한 표본이며, 사용자 속도 경험이나 모든 프로젝트의 생산성 보장으로 해석하지 않습니다.

실제 공개 요청·응답과 구조화된 이벤트를 보존합니다. 비공개 내부 추론 전체, 비밀값, 인증 정보는 여기에 포함하지 않습니다. 운영 후보의 검증을 외부 배포·장기 soak와 혼동하지 말고 미측정 경계를 확인하세요.
