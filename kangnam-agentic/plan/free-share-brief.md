# 5회차: 자유 공유와 토론, 스터디로 (2026-10-29 11:56 강사 결정)

강사 말: “발표 템플릿 형식을 정하는 건 마지막 날 하는 게 말이 안 됨. 자유 형식이면 충분하고 자유로운 토론과 스터디 결과로 이어지게만 해주면 좋겠음.”
(앞선 결정 유지: 채점·평가 없음, ‘점수 없음’ 같은 문구도 쓰지 않음, 하네스 형태 자유, 소개하는 말투, 약어는 교시 첫 등장에서 풀어 씀 — plan/acronym-brief.md)

## 바꿀 것
- **17교시(p17)**: 발표 템플릿(템플릿 5장, 구조도·트랙·실행 기록·실패 장), 5분+2분 규칙, ‘발표 전 확인 여섯 가지’, 같은 기준 과제 강제를 **없앤다.** 대신 짧게(4~6장):
  1. 표지: 오늘은 각자 만든 하네스를 자유롭게 나누고 이야기하는 날
  2. 오늘 진행: 형식 자유(화면·말·데모 무엇이든), 원하는 사람부터, 시간은 대략(교시 구성만 안내: 17 열기 → 18·19 나누기와 토론 → 20 정리)
  3. 이야기 거리(토론을 여는 질문 카드, 강제 아님): 내 하네스는 무엇을 맡기나 / 가장 잘 막은 것·못 막은 것 / 다음에 더할 장치 / 남의 하네스에서 가져가고 싶은 것 / 아직 모르겠는 것
  4. 스터디로 이어 가기: 오늘 나온 프롬프트·스킬·스모크 시나리오를 서로 모아 두는 방법(예: 공용 저장소나 문서 하나), 같이 볼 자료 고르기, 다음 모임은 원하는 사람끼리 — 구체적 일정·도구를 지어내지 말고 ‘예’로.
  - 기존 장 중 쓸 수 있는 도식·캡처는 재사용. 모든 장에 이미지·도식·표 중 하나. 새 도식이 필요하면 diagrams/src/*.d2(견본 p17-share.d2), `node tools/diagrams.mjs NAME`.
- **18·19교시(p18, p19)**: ‘발표자 1~8 / 9~16’, 타이머·사회자·전환 1분 규칙, ‘한 문장 질문’ 규칙을 없앤다. 각 2~4장: 표지(나누기와 토론 1부/2부), 진행(원하는 사람부터, 이야기가 길어지면 길어져도 됨), 토론 질문 카드(17교시 것 재사용 가능), 휴식.
- **20교시(p20)**: 정리 내용은 유지. 수료 인사 앞에 ‘오늘 이야기를 스터디로’ 한 장을 넣거나 기존 ‘계속 키우는 법’ 장에 스터디로 이어지는 문장을 더한다.
- **16교시(p16) 26~29장 중 5회차 안내 부분**(‘공유 형식과 실행 기록’, 5분+2분, 같은 기준 과제 실행 기록 표)과 **1교시(p01) 마지막 일정 장의 5회차 행**: “자유 형식으로 나누고 이야기한다, 스터디로 이어 간다”로 맞춘다.
