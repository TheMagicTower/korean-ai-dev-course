단계별 중간 점검
  1. STEP-1 표시 · s2-17: 아래 “실제 기록 1개”와 “빈 배열”을 누릅니다. renderLibraries(items)의 결과를 확인하고 안내 문구를 수정합니다.
  2. STEP-2 로드 · s2-25: 내장 JSON으로 27개를 확인합니다. 로컬 서버에서는 HTTP JSON을 선택하고 ./data/libraries.json을 불러옵니다. 경로를 ./data/missing.json으로 바꾸면 실제 404입니다.
  3. STEP-3 연결 · s2-34: 전체 연결로 돌아온 뒤 포곡 1개, 기흥구 9개, 포곡+기흥구 0개와 초기화 27개를 확인합니다. 함수 정의는 이 HTML의 STEP 주석에서 찾습니다.

이 파일은 세 함수를 연결한 최소 완성 예제입니다. 3회차의 후보 저장 TODO는 별도 starter.html을 사용합니다.

연결 결과

슬라이드와 같은 콘솔 실행 계약
const rows = await loadLibraries();
renderLibraries(rows.slice(0, 1));
renderLibraries([]);
renderLibraries(searchLibraries(rows, { q: ' 포곡 ' }));
console.assert(searchLibraries(rows, { district: '기흥구' }).length === 9);
console.assert(searchLibraries(rows, { q: '포곡', district: '기흥구' }).length === 0);
// 전체 입력 연결로 돌아가려면 위의 “전체 연결로 돌아오기”를 누릅니다.

같은 콘솔에서 const rows를 다시 선언할 수 없으면 다른 변수명을 쓰거나 페이지를 새로고침합니다. 라이브러리와 설치가 필요 없는 일반 JavaScript입니다.

직접 만든 모킹과 실제 HTTP 오류를 구분해 기록합니다. 코드 조각을 강의 홈페이지의 다른 페이지 콘솔에 붙이지 말고 이 파일에서 실행합니다. 데이터와 코드가 모두 내장되어 있으며 외부 파일 읽기는 HTTP 방식을 선택할 때만 수행합니다.
