**주의 (흔한 오해)**
- “Claude Code가 터미널 에이전트의 시초”는 틀림. Aider(2023)가 먼저. “주류로 만든 도구”로 말한다(8장).
- 장치 순서는 날짜가 아니라 문제→해결의 논리. 매달 여러 장치가 동시에 쌓였다(36장). 자동 압축(2025-03)이 Plan 모드(2025-06)보다 먼저(13장).
- 93%·17%는 개발사가 밝힌 수치. auto mode는 “사람의 승인을 모델이 대신한다”로 정확히 말하고 17% 한계를 같이 말한다(20장).
- CI 비용 폭증은 요금 인상이 아님: 단가는 2026-01 최대 39% 내림, 늘어난 것은 실행량(2026-09 Actions 32.6억 회, 전년 대비 4배 넘음)(32장).
- Karpathy guidelines 스킬은 본인이 아닌 제3자가 정리한 것(27장). 1M 창은 Claude·Gemini만, Codex는 400K(24장).
- ‘하네스’는 2025-02 Claude Code 때는 쓰이지 않았고 공식 글에서는 2025-09 Agent SDK(Software Development Kit, 소프트웨어 개발 키트) 글이 처음 확인(25장).
- 스모크 테스트는 동작 여부만 본다. 쓸 만한지는 페르소나 평가 몫이고 시뮬레이션 사용자는 실제 고객과 다르다(34–35장).

**예상 질문**
- “바이브 코딩과 에이전틱 엔지니어링 차이?” → 맡기는 건 같다. 맡겨도 되도록 권한·스펙·테스트 같은 장치를 설계하는지가 다름(4장).
- “하네스가 뭔가요?” → 모델을 둘러싼 장치 전부(권한 규칙·스펙·테스트·루프·도구 연결·진행 기록). 실습에서 내가 원하는 기능의 하네스를 만든다(25장, 형태 강제 없음).
- “오늘 다 이해해야 하나요?” → 훑어보는 소개일 뿐. 장마다 몇 교시에서 자세히 보는지 표시돼 있다.
- “발표는 뭘 하나요?” → 정해진 발표 형식은 없다. 5회차에 각자 만든 하네스를 자유롭게 나누고 이야기하며, 스터디로 이어 가도 좋다(38장).

**시연·준비**
- 표지 네 장(2021 Copilot, 2023 IDE 채팅, 2025 Claude Code, 2026 Orca)은 실제 화면. 4장 Karpathy 게시물은 X 공식 임베드를 강사 브라우저에서 저장한 것이라고 말한다.
- 18장 ‘질문 시간’(약 5분)에서 1·2부 질문을 받는다. 3·4부 표지(19·28장)에서도 짧게 끊어도 됨.
- 13·14·16교시용 강사 화면(Orca·코디네이터·이슈 원장·페르소나)은 해당 교시 몫. 여기서는 예고만. 캡처 대기 장 없음.

- 4교시는 설치 없이 각자 쓰던 에이전트로 진행. 3교시 끝(23장)에 설계 대화로 내 하네스의 첫 버전을 만든다고만 예고(기능·형태는 각자).

**주의 (흔한 오해)**
- 승인 전에 에이전트가 파일을 만들면 안 됨. 질문 없이 코드부터 쓰면 “승인 전에는 파일 만들지 마”로 되돌린다(13장).
- 에이전트가 쓴 설계를 그대로 승인하지 않는다. 판정은 사람(7–8장).
- 5장 설계 질문은 여섯 항목(1·2·3·5·6·7단계). 4단계(마켓)는 개인 도구라 생략.
- 학생은 코드를 읽지 않는다. 에이전트가 낸 증거도 그대로 믿지 않고 직접 한 번 더 시켜 본다(9–10장).
- 7·10·11장의 값(PoC·파일 3개, 7분·9바퀴, 막힘 2/안 막힘 1)은 예시. 숫자는 못 쟀으면 못 쟀다고 적는다.
- 형태·구조는 강제하지 않는다(12장): 질문 순서, 승인 전 다섯 가지, 금지 세 가지, 스모크 시나리오는 모두 강사 방식의 예시이고 각자 바꿔도 된다.

**예상 질문**
- “질문이 끝나지 않아요.” → 남은 것은 추천 답으로 정하라고 시킴(13장).
- “뭘 골라야 할지 모르겠어요.” → 선택지 두 개와 장단점을 표로 달라고 함(5·13장).
- “어떤 방식(코드형/설정형)으로 만들죠?” → 에이전트가 추천하게 하고 이유만 읽음(5장).
- “금지 시험이 안 막혔어요.” → 가장 좋은 발견. 원인 설명시키고 고친 뒤 같은 요청으로 재시도, ADR 갱신. 원인을 적어 두면 다음 시간에 나눌 거리가 된다(10–12장).
- “막힌 채로 두어도 되나요?” → 부담 없이. 어디서 왜 막혔는지 다음 시간에 하나만 나누면 충분.

**시연·준비**
- 프롬프트와 스모크 결과는 슬라이드의 예시로 진행한다(사전 실행 불필요). 예시라는 점만 말해 둔다.
- 설치·로그인 안내 없음. 질문 시간 장 없음 — 설계 대화 중 수시로 받고, 막히면 손들기(13장). 캡처 대기 장 없음.
