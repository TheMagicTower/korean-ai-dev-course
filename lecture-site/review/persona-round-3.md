## 결론의 범위

같은 5명, 같은 25개 질문 ID로 개편 자료를 다시 읽었습니다. **실제 수강생의 이해도·완료 시간·성취도를 측정한 결과가 아닙니다.** 모의 답변은 자료와 가정한 선수지식을 대조해 작성한 예상 설명입니다. 실제 학생이 그 답을 했거나 실습을 수행했다는 뜻이 아닙니다.

검토 자료는 `content/revision/session-1.json`~`session-5.json`, 최종 통합 `content/slides.json`, 학생도 읽을 수 있는 notes, `public/labs/GUIDE.md`, 시작·완성·모듈 예제의 학습용 파일·함수 연결입니다. 통합본에서 시각 자료로 바뀐 `s2-03/s3-05/s4-34/s5-01`의 설명 문구도 대조했습니다. 전체 코드 리뷰·문헌 사실 검증·브라우저 실행·생성 이미지의 시각 품질 검수는 이 점검 범위에 포함하지 않았습니다. 실행 검증과 실제 수업 관찰은 별도의 근거가 필요합니다.

고정 프로필과 원래 질문 전문은 [personas.json](./personas.json), 최초 위험은 [1차 기록](./persona-round-1.md), 수정 전후 인지 경로는 [2차 기록](./persona-round-2.md)에 있습니다. 아래 질문은 원래 질문의 요지이며 ID와 요구 역량을 바꾸지 않았습니다. 모든 학생이 기초 코딩과 유료 AI 사용 경험을 가진다는 공통 조건도 유지했습니다.

**자료상 해결**은 해당 질문을 설명·예제·행동·산출물·대안으로 연결할 수 있다는 뜻입니다. 아래 **수업 통과 조건**은 향후 실제 수업에서 관찰할 기준이며 이번 점검에서 통과한 결과가 아닙니다. 숫자 1·9·27은 고정 스냅샷에 대해 자료가 제공한 기대값이고, 이번 점검의 측정값이 아닙니다.

## 실제 수업에서 남아 있는 확인

자료 검토로 학생의 실제 행동을 대신할 수 없습니다. 첫 운영 또는 파일럿에서는 다음을 확인해야 합니다.

- 설치 없는 기본 경로에서도 파일 저장·편집기·브라우저 전환에 어떤 도움이 필요한지 관찰합니다.
- 2회차 모듈 예제와 3회차 구현 키트의 차이를 학생이 직접 설명할 수 있는지 확인합니다. 두 파일을 계속 혼동하면 이후 운영에서 기본 예제를 더 단순화할 근거로 삼습니다.
- 25분의 두 작업 실습과 30분의 공개 실습에서 실제로 어느 지점에 시간이 쓰이는지 기록합니다. 대안으로 전환한 사실을 실패율이나 성공률로 미리 추정하지 않습니다.
- 실제 대상 사용자 접근, 동료의 도움, 제출 자료의 독립적인 설명을 확인합니다. 동료 관찰과 가상 검토를 시장 검증으로 바꾸지 않습니다.
- 조건 변경 질문에서 학생이 자신의 판단과 추가 검사를 설명하는지 확인합니다. 슬라이드의 정답 선택과 실제 문제 해결을 같은 성취로 보지 않습니다.

3차 자료 검토의 종료 기준은 발견한 연결 오류를 수정하고 동일 질문에 대응하는 근거가 있는지 확인하는 것입니다. 실제 학습 효과·완료율·수업 시간의 적정성은 수업 관찰 전까지 미확인으로 남습니다.
