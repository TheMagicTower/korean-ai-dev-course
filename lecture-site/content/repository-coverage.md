## 이번에 보완한 부분

최초 인계와 공개의 시간 차이, 사용 범위와 완료 단계, 도입·재사용 판단, 스펙·계획·ADR, 한국어 스킬8개와 세션 인계, 중복 이슈·연관 이슈·PR 단위, Linear CI 측정, ApplyFlow 파일 변경 중 검토 무효화, 고도화·부분 교체·재구현, Signal 서버 계약 비교를 슬라이드에 보완했습니다. FlyBlock과 Jev는 앞뒤 실습의 입출력 계약으로 돌아오는 문장을 추가했습니다.

기존에 포함된 공공데이터의 기준일·제약, 책임 경계·TDD·소비자 검사, 머지트레인·누적 검사, 스모크·가상 사용자·모킹·실제 관찰, 공개·복구·피드백은 유지했습니다.

## 선택 자료로 남긴 이유

- 공급사별 파라미터·상품·가격: 빠르게 바뀌므로 선택 원칙만 필수로 설명하고 사용 시점의 공식 명세를 확인합니다.
- 전체18단계 운영·조직형 CD: 원본 체계를 소개하되 개인 MVP에 모든 자동화와 회의를 설치하지 않습니다.
- 신경과학 연구와 신경 시뮬레이터 실행: 경계·근거 해석이 수업 목적입니다. 새 연구 환경 설치는 필수가 아닙니다.
- 내부 제작 계획·원시 실행 로그: 관측한 수치와 구현 범위를 확인하는 근거이며 강의 시간을 늘리는 별도 단원이 아닙니다.
- 원본8시간 과정: 학습 주제는 계승하고 시간표는 이번20시간 계획으로 대체합니다.
