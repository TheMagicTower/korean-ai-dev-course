좋은 기회를 모으고,
다음 행동을 놓치지 마세요.

흩어진 채용 공고를 한곳에 모아 관심부터 지원·면접까지 이어갑니다.

현재 구현 범위: 공고 저장·지원 상태 변경·검색·필터·이 브라우저 저장·JSON 백업 가져오기·내보내기·개별 삭제. 로그인·사용자별 서버 저장·마감 알림·공고 자동 수집은 미구현입니다. 실제 이력서·연락처를 입력하지 마세요.

3단계로 시작하세요

  1. 기회를 담으세요. 가상 공고 3개로 시작하거나 직접 입력합니다.
  2. 진행 상황을 바꾸세요. 지원·면접 상태와 검색으로 다음 행동을 찾습니다.
  3. 백업을 챙기세요. JSON으로 내려받고 가져오기에서 내용을 확인한 뒤 복원합니다.

개인 브라우저 도구입니다. 현재 기기에만 저장되며 브라우저 데이터 삭제 시 사라질 수 있습니다.
