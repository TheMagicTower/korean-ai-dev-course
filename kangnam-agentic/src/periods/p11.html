Claude Code는 설명을 1,536자에서 자르므로 핵심을 앞에 둡니다. 반대로 배포처럼 사람이 결정해야 하는 스킬은 모델 호출을 꺼서 설명 자체를 컨텍스트에서 뺍니다.

오늘 본 것을 묶으면, 스킬은 SKILL.md가 든 폴더이고, 점진적 공개로 필요할 때만 읽힙니다. Superpowers는 설계, 계획, 서브에이전트 실행, TDD를 묶은 방법론이고, Karpathy guidelines와 Ponytail은 에이전트가 과열하지 않게 하며, Anthropic 공식 스킬은 만들기와 문서, 화면, 테스트의 도구 상자입니다. 오른쪽 화면처럼 같은 스킬을 에이전트마다 폴더로 나눠 배포하는 일이 오픈 표준 이후의 모습입니다. 다음 12교시는 실습입니다. 여러분의 작업 방식을 스킬 하나로 만들고, MCP를 하나 연결하고, 긴 작업을 맡겨 봅니다. 오늘 쓴 description 한 문장을 가지고 오시면 좋습니다.
