# ApplyFlow 실행 예제

가상의 취업 준비 서비스 프로토타입입니다. 학생은 자기 아이디어를 선택하며 이 예제 구현을 그대로 제출할 필요는 없습니다.

## 실행

저장소 루트에서 `python3 -m http.server 8765`를 실행하고 `http://localhost:8765/course/examples/applyflow/`를 엽니다. HTTPS Pages에서도 실행할 수 있습니다. HTML 파일 더블클릭보다 HTTP 서버 실행을 사용하세요.

`node course/examples/applyflow/test-model.cjs`로 데이터 계약 테스트를 실행합니다. 추가 패키지 설치는 없습니다.

## 구현 범위

- 회사·직무 입력, 공백·길이 검증, 최대200개
- 관심·지원·면접·합격·종료 상태와 필터
- 동일 브라우저 localStorage 저장, 저장 실패 시 기존 상태 유지
- 손상 저장 감지 시 덮어쓰기 중단
- 다른 탭의 저장 변경 읽기, JSON 백업 다운로드(가져오기 미구현)

상태는 어느 단계로도 수정할 수 있습니다. 과거 기록 입력과 오입력 수정이라는 사용자 시나리오에 따른 선택입니다.

## 미구현·운영 한계

로그인·서버·사용자별 접근 분리·마감 알림·채용 사이트 수집·결제·동시 편집 충돌 해결은 없습니다. 실제 개인정보나 이력서를 넣지 마세요. 브라우저 자료를 지우면 저장한 공고도 사라집니다. 다른 기기로 자동 동기화되지 않습니다. 여러 탭의 동시 변경은 마지막 저장이 이전 변경을 덮을 수 있습니다. 실제 팀·다중 사용자 운영용으로 제공하지 마세요.

저장 자료가 손상되면 편집을 중단하고 원본을 보존합니다. 원본을 별도로 확보하기 전 저장 영역을 삭제하지 마세요. 원인 확인 후 테스트 환경에서 복구 방법을 결정합니다.

## 수동 실습

1. 빈 목록에서 가상 공고3개 추가 → 다시 추가 버튼 비활성 확인.
2. 새 가상 회사·직무 저장 → 목록과 총수 확인.
3. 상태를 면접으로 변경 → 면접 필터에서 확인.
4. 새로고침 → 공고·상태 유지 확인(필터는 기본값으로 돌아감).
5. 공백 입력 → 거부 확인, 문자 `<b>test</b>` 입력 → HTML 실행 없이 문자로 표시 확인.
6. JSON 백업 → 파일 내용과 화면 비교.

실제 서비스 MVP는 교재의 사례 단원에서 제시한 인증·본인 데이터 접근·배포·새 세션·사용자 피드백 증거가 추가로 필요합니다.
