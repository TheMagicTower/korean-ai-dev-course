# ApplyFlow 프로젝트 실행 매뉴얼 계획

사용자 요청: 실제 서비스 사례 하나를 온보딩·프롬프트·계층별 작업 분해·수행·인계까지 연결해 문서화합니다.

기존 ApplyFlow를 활용하고 AF-104 회사·직무 검색 작업을 실제 수행 표본으로 추가합니다. 검색은 저장된 공고의 부분 문자열(대소문자 무시·앞뒤 공백 제거)을 상태 필터와 AND로 적용합니다. 빈 검색은 기존 결과, 결과 없음은 안내, 검색은 저장 데이터를 변경하지 않으며 검색어는 재실행 시 초기화합니다. 서버·인증·외부 검색은 이 Task에서 제외합니다.

작업: model.selectJobs와 계약 테스트 → 입력과 목록 연결 → 브라우저 교차 필터·초기화·빈 결과 확인 → 실행 근거 기록 → 교재 새 단원 배포.
문서: 복사용 프로젝트 시작/온보딩/스펙/계획/구현/검토/판단/인계 프롬프트, M→Stage→Sprint→Task 매핑, 목표 서비스와 현재 데모 범위, 증거를 통한 상태 전이.
자동 상태 머신·Jev 통합 구현은 요청 범위에 포함하지 않습니다. 프롬프트는 재현을 위한 교육용 재구성이고 과거 대화 원문이라고 표현하지 않습니다.
