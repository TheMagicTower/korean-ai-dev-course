# D2 도식 재작업 지침

프로젝트 루트: /tmp/claude-0/-home-claude/1e61c45b-9ca0-544b-985f-74ce7a96fb3a/scratchpad/ka (모든 명령은 여기서)

문제: 많은 도식이 한 줄로 길게 늘어져(가로세로비 5:1 이상) 슬라이드에서 글자가 10px 수준으로 작아지거나, 간선 라벨이 화살표·상자 위에 겹칩니다.
목표: 1600×900 슬라이드에서 상자 글자가 **최소 20px**로 보이고, 간선이 상자·글자를 가로지르지 않으며, 라벨이 겹치지 않게.

## 규칙
- 렌더러는 D2 + ELK. `grid-columns`/`grid-rows`는 쓰지 않습니다(간선이 직선으로 상자를 관통함).
- 긴 흐름은 **행 컨테이너로 줄바꿈**합니다: 최상위 `direction: down`, 그 아래 행 컨테이너 2~3개에 각각 `direction: right`, 행당 상자 3~4개. 행 사이는 마지막 상자 → 다음 행 첫 상자로 연결. 행 컨테이너는 라벨을 비우고(`row1: "" {…}`) 테두리 없이 `style.stroke-width: 0; style.fill: transparent` 처리.
- 간선 라벨은 6자 이하로 줄이거나 없앱니다. 설명이 필요하면 상자 글자에 넣습니다. 되돌아가는 간선(루프)은 1개까지만.
- 상자 글자는 줄당 12자 안팎, 최대 2줄.
- 도식이 놓인 자리를 확인합니다: 두 단(.row) 안이면 세로형(가로세로비 0.8~1.3), 전체 폭이면 가로세로비 1.8~3.
- 파일 끝의 글자 크기 두 줄은 유지합니다: `**.style.font-size: 34` / `(** -> **)[*].style.font-size: 26`
- 강조는 `style.stroke: "#ff00ff"`만.
- 내용(무엇을 말하는 도식인지)은 바꾸지 않습니다. 필요하면 상자 수를 줄이고 나머지는 슬라이드 본문에 이미 있으니 생략.
- 도식만으로 안 되면 그 슬라이드의 마크업에서 도식 자리를 넓히는 것(예: `.row`의 열 비율 조정, 도식을 아래로 내려 전체 폭으로)은 허용. 다른 슬라이드·공용 파일은 수정 금지.

## 확인
1. `node tools/diagrams.mjs 이름` 
2. `python3 tools/build.py pNN` 후 `NODE_PATH=$(npm root -g) node tools/qa.js pNN` (넘침 0)
3. 해당 슬라이드 `qa/pNN/sXX.png`를 Read로 직접 보고 글자 크기·겹침 확인. 슬라이드 번호는 그 교시 파일 안에서 `{{svg:이름}}`이 들어 있는 section 순서(1부터).
