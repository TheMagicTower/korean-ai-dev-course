# 내 아이디어를 4주 안에 완성품으로

매주 2시간, 하나의 프로젝트를 끝까지 이어갑니다. 이 과정의 결과는 코드가 많은 저장소가 아니라 **합의한 사용자가 실제로 쓸 수 있는 작은 도구**입니다.

<!-- visual:journey -->

## 시작하기 — 읽는 순서

1. 아래 주차 지도에서 이번 주 단원으로 이동합니다. 매주 개념 → 시연 → 내 프로젝트 실습 → 완료 확인 순서로 진행합니다.
2. 실습 프롬프트를 복사하고 자신의 사용자·입력·결과로 바꿉니다.
3. 체크리스트는 이 브라우저에 저장됩니다. 최종 증거는 프로젝트 문서에도 남깁니다.

주제는 자유입니다. 독서 기록, 문의 정리, 개인 일정, 파일 변환, 작은 내부 업무 도구 등에서 핵심 흐름 하나를 고르세요. 로그인·결제·실시간 협업이 핵심이 아니면 첫 버전에서 제외합니다.

필수는 순서대로 진행하고, 선택은 필요할 때 해당 주차의 선택 읽기에서 엽니다.

| 구분 | 단원 | 읽는 시점 |
|---|---|---|
| 필수 4주 | 시작하기, 1주차, 2주차, 3주차, 4주차 | 매주 순서대로 끝까지 진행합니다. |
| 선택: 사례·실습 | 사례 선택, ApplyFlow·FlyBlock·매거진 사례, 실행 매뉴얼·수행 기록, 제작실·업데이트·비교 기록 | 주차 본문의 선택 읽기에서 목적에 맞는 것만 고릅니다. |
| 선택: 협업·통합 심화 | 이슈·PR 관리, DDD·TDD와 테스트 경계, CI/CD 측정·캐시, 머지트레인, 고도화·재구현 판단 | 2–4주차 선택 실습 시간에 대체 과제로 사용합니다. |
| 선택: 도구·서식 | 워크북, 모델·프로바이더, 주요 모델 자료, 코딩 에이전트, 스킬 안내 | 필요할 때 참조합니다. 모두 설치·구독하지 않습니다. |
| 선택: 운영 기준·강사용 | 완성 수준, 수준별 프로세스, 전체 워크플로우, 18단계 기준, 강사 과정 설계 | 완성 판정과 수업 운영의 근거로 참조합니다. |

## 4주 전체 과정 — 총 8시간

**이 교재에는 1–4주차 본문이 모두 포함되어 있습니다.** 아래 주차를 누르거나 목차에서 이동하세요. 각 주차에 120분 진행표, 개념 설명, 강사 시연 안내, 실습 프롬프트와 완료 체크리스트가 있습니다.

| 바로가기 | 이번 주에 할 일 | 이어갈 산출물 |
|---|---|---|
| [1주차 · 문제와 시작](#week1) | 사용자·완료 수준·모델과 도구 선택, 첫 실행 | 프로젝트 계약·첫 목업 |
| [2주차 · 목업에서 구현으로](#week2) | 시안을 조작하고 규칙·API·데이터를 도출해 구현 | 실제 저장과 연결된 핵심 흐름 |
| [3주차 · 디버깅과 검증](#week3) | 재현·수정·검토, 모델 비교와 목표 환경 실행 | 검증 기록·제출 후보 |
| [4주차 · 완성품 전달](#week4) | 패키징 또는 배포, 실제 사용·인계·회고 | 실행 결과·사용법·증거·다음 계획 |

학생 각자의 아이디어를 네 주 동안 이어갑니다. 매주 새 프로젝트를 만드는 방식이 아닙니다. 현재는 네 주 전체의 **첫 교안**이며, 녹화 시연이나 환경별 완성 예제 코드가 모두 제공되는 상태는 아닙니다.

## 필수 사전준비 — 수업 시간 밖 환경 확인

- Codex 또는 Claude Code 중 접근 가능한 도구 하나와 계정을 준비합니다.
- 빈 프로젝트 폴더를 만들고 해당 폴더에서 에이전트를 시작합니다.
- 코드 실행에 필요한 환경은 선택한 프로젝트 기술에 맞게 준비합니다. 기술이 미정이면 강사 지원을 받아 가장 작은 실행 방식부터 선택합니다.
- API 비용이 발생한다면 본인 계정의 사용량과 예산을 확인합니다. 교재에는 API 키를 적지 않습니다.

스킬 설치는 [스킬 패키지 문서의 ‘학생용 설치’](../docs/korean-skill-package.md)에서 버전·다운로드·도구별 설치 요청문을 그대로 복사해 진행하세요.

## 자료 위치 — 필요할 때 여는 곳

- **따라 할 사례:** [사례 선택 안내](cases/index.md)에서 ApplyFlow·FlyBlock·매거진 중 하나를 고릅니다. 실행 예제·실행 매뉴얼·수행 기록·제작 기록도 그곳에서 연결됩니다. 각자 하나의 프로젝트만 선택합니다.
- **완성 기준:** 기본은 개인 완성 도구 또는 제한 사용자 MVP입니다. 중요한 원본을 삭제하거나 돈·외부 전송을 다루면 개인용이라도 해당 위험 검증을 추가합니다. 자세한 판단은 [완성 수준](../docs/project-completion-levels.md)을 보세요.

## 교재의 현재 범위

이 자료는 첫 교육용 버전입니다. 시간표는 각 주 120분으로 구성했지만 실제 수강생 파일럿을 수행한 결과는 아닙니다. 모델 정보는 2026-09-22 공식 자료 조사 기준이며 접근 가능한 모델·가격은 수업 전에 다시 확인합니다. 모든 프로바이더 구독과 모든 에이전트 설치는 필수가 아닙니다.
