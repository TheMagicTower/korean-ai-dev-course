교육용 스냅샷 · 총 좌석 수는 기준일의 좌석 규모입니다. 실시간 잔여 좌석은 추가 확인 항목입니다. 현재 개관 여부는 공식 운영 안내에서 확인합니다.

완성 조건을 직접 확인합니다
  1. 검색어 포곡은 1개, 기흥구 필터는 9개, 두 조건을 함께 쓰면 0개입니다.
  2. 0개 결과에서 조건을 초기화하면 27개 기록으로 돌아옵니다. 저장한 후보는 유지합니다.
  3. 후보 저장 → 저장한 후보만 보기 → 새로고침으로 저장 상태를 확인합니다.
  4. 읽기 실패와 저장 실패 모킹을 각각 켜서 안내와 복귀를 확인합니다.

시작 파일은 미완성 부분을 표시한 학습 자료입니다. 완성 예제의 코드와 비교하기 전에 자신의 기대 결과를 먼저 적습니다.

실습용 실패 모킹 · 학생이 조건을 선택해 오류 안내와 복구 동작을 확인합니다.
