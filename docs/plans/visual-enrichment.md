# 교재 시각 자료 확장 계획

2026-09-23. 사용자가 전체 교재에 차트·그래프·그림 보강을 요청했습니다.

기존 크림·청록색 편집 스타일을 유지합니다. 본문 사이에 설명 가능한 시각 자료를 배치하고, 모든 시각 자료에는 제목·캡션·텍스트 대안을 둡니다. 교육 예시를 실측 성능으로 표시하지 않습니다.

1. 시작: 네 주 산출물 여정 그림과 실제 시간표 기반 차트.
2. 1주: 모델·프로바이더·에이전트·스킬 관계 도해 및 완료 수준 매트릭스.
3. 2주: 조작 가능한 문의 목업과 그 행동에서 도출하는 규칙·계약·데이터 그림.
4. 3주: 비용·재시도 입력에 따른 교육용 그래프와 재현/수정/재검증 흐름.
5. 4주: 검토·CI·배포·사용 확인 게이트 그림과 제출물 지도.
6. 전체 워크플로우·모델·에이전트 부록에도 개념도를 제공.

구현: 별도 HTML 조각과 CSS/JS를 빌드 시 삽입해 index.html 하나로 유지. 차트는 표 기반 실데이터, 비용 그래프는 사용자 입력 산술식. 외부 시각화 라이브러리 불필요. 기존 본문과 체크리스트 키를 유지.
검증: 빌드·차트 산술 검증, 모바일/데스크톱 화면, 키보드 조작과 변경 출력, 공개 배포 바이트 일치.
