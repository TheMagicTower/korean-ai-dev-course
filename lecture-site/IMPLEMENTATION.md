# 강남대 AI 소프트웨어 엔지니어링 강의

## 목표와 확정한 구성
2026-10-22 사용자 요청에 따라 20시간 강의, 인터랙티브 HTML 슬라이드, 공개 홈페이지, 실제 공공데이터 데모, 과제 제출과 비공개 평가·피드백을 구현하고 Cloudflare에 배포합니다. 5회 4시간을 기본으로 4회 5시간 대안을 제공합니다. 0교시에는 세상을 긍정적으로 바꾸는 아이템 한 가지를 준비합니다. 게임·서비스·물리 제어 모두 가능하며 공공데이터 활용은 권장 선택입니다.

## 구조
- public/: 프레임워크 없이 접근 가능한 HTML·CSS·ES modules. 학습 자료는 공개합니다.
- content/: 강의, 실습·과제, 출처 데이터. build.mjs가 public/content에 복사합니다.
- worker.js + migrations/: Cloudflare Worker, D1, 학생 확인 코드와 강사 비밀번호 인증, 비공개 과제·평가·버전 관리.
- tests/: 인증 격리, 동시 수정 충돌, 제출·평가·재조회, 보안 오류와 공개 페이지 검증.

## 디자인
기존 교재의 종이색과 녹색을 계승합니다. 강한 타이포그래피, 차분한 여백, 단계별 번호를 사용합니다. 강의 슬라이드는 키보드·목차·발표자 노트·전체 화면·인터랙티브 예시를 제공합니다. 개인 사례와 벤치마크, 실제 실행 사례와 설계 실습을 구분합니다.

## 실행 순서
1. 공식 자료와 기존 저장소 근거를 확인하고 회차별 진행안·실습·과제를 작성합니다.
2. 홈페이지·슬라이드·공공데이터 데모를 작성합니다.
3. 학생 제출·복구 코드·강사 평가 API와 화면을 연결합니다.
4. 로컬 D1에서 두 학생의 접근 격리, 수정 충돌, 점수·피드백과 재제출을 확인합니다.
5. 데스크톱·모바일 렌더링, 키보드, 페이지 링크와 브라우저 오류를 확인합니다.
6. 새 Cloudflare Worker와 D1을 배포하고 실제 URL에서 공개 접근과 제출·평가 왕복을 확인합니다.

## 운영 범위
학생은 이름 또는 별명을 사용합니다. 확인 코드가 본인의 과제·피드백 접근 권한이므로 별도 보관을 안내합니다. 강사 비밀번호는 Cloudflare secret이며 저장소나 공개 파일에 넣지 않습니다. 초기 제출은 글과 HTTPS 링크를 받으며 파일 업로드·이메일 발송은 포함하지 않습니다. 기존 8시간 교재와 데모는 수정하지 않습니다.
